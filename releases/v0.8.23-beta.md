## Build and platform changes

- Updated both compile SDK and target SDK from 35 to **36**. Minimum SDK remains **21**.
- Updated Android Gradle Plugin to **8.10.1** and the Gradle wrapper to **8.11.1**, with the distribution SHA-256 pinned. Built with a full JDK 17.
- Kept Kotlin 2.0.21, Media3 1.5.1, channel data, source seeds, guide configuration, logos, and startup-animation content unchanged.
- Replaced legacy system-UI flags with WindowCompat / WindowInsetsControllerCompat. Video remains edge-to-edge; existing safe-inset handling continues to protect interactive overlays.
- Kept AndroidX Back dispatch and explicitly enabled the platform Back callback. No dependence on legacy KEYCODE_BACK dispatch on Android 16.
- Applied Android 16's documented temporary restricted-resizability compatibility property to MainActivity to preserve the existing explicit landscape-lock toggle. The activity remains resizable. This property stops applying at target API 37 and must be revisited for that migration.

## Validation

- **102 Android JVM tests passed.**
- APK build, release-bundle build, and lint completed: **0 lint errors, 111 warnings**. The updated lint includes additional recommendations such as UseKtx; warnings have not been hidden to claim a clean report.
- APK manifest verified: compile SDK 36, target SDK 36, minimum SDK 21, version code 43.
- Signature matches 0.8.22-beta; API 21+ signature and 16 KiB ZIP alignment checks passed.
- Channel catalog, source seeds, guide configuration, logo index, and startup-video content were compared with 0.8.22-beta and preserved.

Android 16 hardware behavior, old-device compatibility, rotation, Back gestures, system-bar overlap, PiP, and long-session playback remain **UNVERIFIED on physical devices**. Build and unit tests do not establish production reliability or Google Play approval.

## Store submission boundary

An unsigned release AAB was generated as a build artifact. It is not a production-signed upload bundle. The operator still needs a securely managed upload key / Play App Signing setup, real phone/tablet/TV screenshots, review access for restricted caption features, content-rights checks, and accurate Play Console declarations.

The APK linked above is a beta review build. Install it over a matching-signature beta to retain data and device approval. No new Groq key, re-pairing, or server redeployment is required for this update.
