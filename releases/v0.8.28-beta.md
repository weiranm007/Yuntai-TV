## Changes

- With native foreign-caption translation enabled, hide original foreign text while waiting and on translation failure; show Chinese results without the previous original-text flash. Original captions remain available when translation is switched off. Bitmap or burned-in captions are outside this text-only replacement.
- Deduplicate rolling native captions and merge rapid consecutive cues into bounded batches rather than overwriting pending text with the latest cue. Short initial coalescing, bounded context and stale-result rejection prioritize timeliness without an indefinitely growing queue. Requests remain paced to respect existing quotas; no measured 1–2 second latency guarantee is made.
- Translate meaning and tone into idiomatic Simplified Chinese using up to 600 preceding characters as reference. Preserve names, numbers and negation, translate only current content and do not invent missing facts. Model quality remains subject to device/user acceptance.
- Reorganize settings hierarchy: stronger 20sp group headings, regular 16sp setting labels and 14sp choices, with consistent section spacing. Retain the existing dark theme and blue confirmation actions.
- Replace two processing-consent checkboxes with one explicit audio/subtitle-text processing choice. Existing users must reconfirm; old consent is not silently expanded. Global caption and foreign-text-translation switches remain independent.
- New private-beta pairing uses one four-digit code with five-minute expiry, collision-safe Firestore reservation and owner CLI confirmation. No fingerprint needs to be typed. Existing approvals persist; legacy code format remains readable. No public self-approval or shared API secret is added.
- Remove hidden-status-bar spacing above the top menu. Paint the menu background to the screen edges while keeping interactive content clear of actual system bars and cutouts. Preserve bottom navigation safety.
- Distinguish operator quota, provider throttling and concurrent-task busy messages from fixed server error categories. Keep retry delays and server-side protections. Add sanitized translation exception and 429 diagnostics.
- Fix the companion update script to use /v1/health rather than /healthz.

## Server update required

Upload the service ZIP to Cloud Shell and run:

```bash
unzip -o yuntai-caption-service-0.8.28-update.zip -d yuntai-caption-update-028
cd yuntai-caption-update-028
bash services/update_caption_service.sh
```

Then use this package's administrator script for new devices:

```bash
python3 services/beta_devices.py --project yuntai-app approve 0042
```

Replace 0042 with the actual device code and confirm with `y`. Retain leading zeroes. The update preserves existing authorization mode, approvals, secret references and quota settings. It has not been deployed by the assistant. APK 0.8.28 contextual translation requires this companion update; do not assume an older backend accepts the added context field. See [the operator guide](../docs/NATIVE_SUBTITLE_UPDATE-0.8.28.md).

After installing, open AI subtitle settings, reconfirm combined processing consent, enable the desired global switches and save. The server retains separate audio/text request consent headers derived from that one explicit user choice.

## Validation and limits

- 118 Android JVM tests passed; 128 Python tests passed, including local Firestore SDK/REST integration, collision and concurrent pairing tests, approval cancellation, signatures/replay and authorization lifecycle. No Python tests skipped in the final local-emulator run.
- APK/AAB builds and six-case instrumented test APK compilation completed. Instrumented cases were not run on a device.
- Android lint: 0 errors, 121 warnings. APK/AAB signatures, retained upload certificate, ZIP integrity, API 24 minimum / API 36 target, and 16 KiB APK ZIP alignment checked. Production channel/source/guide/logo/startup assets preserved; generated baseline profiles change with code.
- Physical-device menu positioning/focus, semantic translation quality, end-to-end caption latency, provider quotas and long-session playback remain unverified.
- An owner-reported busy message in 0.8.27 indicates HTTP 429. The operator-versus-Groq origin remains unverified pending failed-request logs. Three supplied successful calls (0.64–0.86 s) do not diagnose the intermittent failure. This release does not raise quotas or claim to solve provider capacity. Default shared inference limits can constrain multiple simultaneous caption users.

The APK is for sideload testing; the AAB is for Play Console and cannot be installed directly. Google Play app-signing certificates can differ from the upload certificate; use Play updates if an APK signature differs, rather than uninstalling to force an update. No release was submitted to Google Play review by this workflow.
