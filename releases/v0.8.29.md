## Changes

- Rename the settings entry, dialog and enable switch to **Yun · 字幕**. Remove the visible experimental label and version suffix. The version is 0.8.29, build 49.
- Keep exactly one subtitle feature toggle. When enabled with processing consent, prefer native Chinese text, translate available foreign text to Simplified Chinese, and use consented audio recognition/translation when usable native cues are absent. No separate native-text translation switch is required.
- Keep one explicit combined audio/text-processing checkbox, device authorization and privacy information. Saving is disabled until settings change; enabling without consent reports and focuses the consent option. Outside taps cannot dismiss this settings dialog.
- Preserve existing fully enabled, consented workflows. Earlier partial audio-only settings do not silently enable additional text uploads; open Yun settings, enable the single switch and save. Fresh installations remain off by default. No API key is bundled and authorization is unchanged.
- Retain prior Chinese-only translated-text presentation, bounded cue batching/context, source maintenance, channel IDs/favorites, startup animation and top-menu positioning fix.

## Installation and service compatibility

Install the APK for sideload use, or upload the AAB through Play Console. AAB files cannot be installed directly. The existing upload certificate and application ID com.yuntai.android.apps.livetv are retained. Google Play's app-signing certificate can differ; update Play-installed builds through Play if signatures differ rather than uninstalling to force an update.

After installing, open **Settings → Yun · 字幕**, enable it, grant the combined processing consent if needed, and save. Previously approved devices do not need reapproval. Existing deployed 0.8.28 translation endpoints are compatible; this UI update needs no additional server deployment.

The optional 0.8.28.1 server quota patch and the owner-authorized one-time daily reset are separate server actions. This APK neither changes quotas nor resets counters, bypasses authorization, increases Groq limits, or promises that every device can consume its full allowance despite shared global caps.
